# ToGo

Mobile-first PWA для планирования отдыха вечером после работы, на выходные и для
коротких поездок.

## Что реализовано

- Быстрый подбор отдыха по времени, бюджету, дороге, транспорту, количеству
  человек и настроению.
- Сценарии "остаться дома", "рядом с домом", "недалеко съездить" и "уехать".
- Режим "отдохнуть бесплатно".
- Карточки вариантов с дорогой, стоимостью, погодой, жильем, едой и местами.
- Детальная страница варианта.
- Редактируемые чек-листы.
- Сохранение планов, настроек и чек-листов в localStorage.
- PWA manifest и service worker для базовой offline-friendly работы.
- Моковые данные и сервисный слой, готовый к замене на реальные API.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Важные ограничения

Интеграции с погодой, билетами, жильем, ресторанами и событиями сейчас
реализованы моковыми данными. Для production-версии стоит подключать только
официальные или партнерские API и учитывать правила использования внешних
сервисов.
